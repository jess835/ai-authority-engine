# AI Authority Engine — Student Quick Start (the Claude Code way)

This is the simple path. You are not going to write code or memorise commands. You are
going to open a folder in Claude Code and have a conversation. Claude Code does the setup
for you and, when you are done, runs the whole thing on autopilot.

**What you end up with:** a system that watches your client's podcast, and every time a
new episode drops, transcribes it, files it in Notion, and turns it into a Brief plus 18
pieces of ready-to-review content. You run it for your clients as a done-for-you service.
Your client never touches it.

**How long it takes:** about 20 to 30 minutes the first time, most of which is you
creating two free accounts. Adding another client later takes about 10 minutes.

---

## The one idea to understand first

Claude Code is an assistant that can read this project and do the technical work for you.
The project has been set up so that the moment you open it in Claude Code, it knows how to
walk you through everything. You lead with plain English, it handles the rest.

So this whole guide really comes down to: get the folder, open it in Claude Code, and say
**"Help me set this up for my client."** Everything below is just so you know what to
expect.

---

## Before you start, have these ready

You do not need to set these up perfectly. Claude Code will guide you through the fiddly
parts. Just know you will need:

1. **Claude Code** installed on your computer.
2. **An OpenAI account** (this powers the transcription and the content). You will add a
   few dollars of credit to it.
3. **A Notion account** (this is where all the content gets stored). The free plan works.
4. **Your client's podcast** name or Apple Podcasts link.

That is it. No servers, no other software.

---

## Step 1 — Install Claude Code

Follow the official install instructions for Claude Code and sign in. If you already use
it, skip this step. If you get stuck here, this is the one place to ask your coach, since
everything after this happens inside Claude Code.

---

## Step 2 — Get the project onto your computer

Open Claude Code and tell it, word for word:

> "Clone https://github.com/jess835/ai-authority-engine and open it"

Claude Code downloads the project and moves into the folder for you. That is the whole
step. You finish with the project open in Claude Code.

---

## Step 3 — Say the magic sentence

With the project open in Claude Code, type:

> **"Help me set this up for my client."**

From here you are just answering questions. Claude Code already knows the steps. It will
lead you through each one and do the technical work itself.

---

## What Claude Code will walk you through (so nothing surprises you)

You do not action these yourself. This is just what the conversation covers:

- **Your keys.** It helps you grab your OpenAI key and your Notion key, and it puts them
  in the right place for you. It will never post your keys back in the chat.
- **Your client's podcast.** You give it the show name or Apple link. It finds the podcast
  feed for you and shows you the latest episodes so you can confirm it is the right show.
- **Your Notion space.** It creates the two databases this client needs inside your Notion,
  so their content has a home.
- **The first run.** It transcribes the newest episode and shows you the new entry in your
  Notion. This is the moment you see it actually working.

When this is done, you have a real transcript of a real episode sitting in Notion, with
zero manual work from you.

---

## Step 4 — Turn one episode into 18 pieces of content

Once a transcript exists, tell Claude Code:

> "Generate the content for the latest episode."

It produces a Brief and 18 assets (titles, articles, social posts, an FAQ, and more) and
files them in your Notion Assets database. Most of them are marked "pending" so you can
review and approve them in your client's voice before anything goes out. A few low-risk
ones are pre-approved. Open Notion, read through them, and edit anything you want.

---

## Step 5 — Put it on autopilot

This is the payoff. Tell Claude Code:

> "Set this to run every morning and tell me what it found."

Claude Code schedules a daily check. From now on it watches the feed for you, transcribes
new episodes automatically, and reports back. A podcast drops weekly, so one check a day
is plenty. You never have to remember to run anything again.

---

## Adding another client

Each client gets their own copy so their content never mixes. To add a second client, ask
Claude Code:

> "Help me set this up for another client."

It will make a fresh copy of the project and walk you through Steps 3 to 5 again with the
new client's details. About 10 minutes.

---

## If something goes wrong

Just tell Claude Code what happened, in plain words: "it gave me an error," or "nothing
showed up in Notion." It keeps a log of every run and can read it, explain what went
wrong, and fix it. You almost never need to leave the conversation.

---

## What you are actually selling

When you run this for a client, you are making their expertise readable to AI. Their
podcast stops being audio trapped in one app and becomes transcripts and content spread
